Points:
1. Environment variables: 11 customer variables have a value in production but none in UAT (dg_AppID, dg_EnvironmentURL, the queue variables dg_CentralComplaintManagementQService, dg_HODQService, dg_LogisticsQService, dg_MarketingQService, dg_ProductHeadQService, dg_ProductTeamQService, dg_QAQCQService, and dg_QueueDPLSales is the same as its default). A UAT-based environment would run flows and scripts with the defaults, not production values. Values must be set after creating any environment. UAT also has msdynci_scaleUnitUri, which production lacks.
2. Connection references: production has 119 of 163 with a connection set; UAT has 21 of 245. Connections are not copied with an environment, so flows will be disconnected until each is set. UAT carries 114 references production does not have.
3. Canvas apps: UAT has 4 more (crcbc_funnel, crcbc_page1, crcbc_page2, dg_rejectreason) and a custom connector (SAP customer outstanding) that production lacks.
4. Duplicate detection rules: UAT has 12 extra customer rules (Account_GST, Account_PAN & Customer Status, Contact Duplicate, Rule 1 to Rule 3, and others). Six standard rules are unpublished in UAT (state 0) and published in production (state 1).
5. Site maps: different (UAT "DPL Sales Masters", production "Dynamics 365 Portals").
6. Custom relationships: 59 only in UAT (mostly portal and file attachment ones, for example FileAttachment_Product_dg_MSDS), 29 only in production (including dg_dg_freightmaster_quotedetail_Freight, dg_task_dg_customervisit and agentic ones from newer Microsoft solutions).
7. Same in both: field security profiles, email templates (49 of 50).

## B10: layering (from earlier production reads, not a new read)
Existing layer data covers only 24 components tied to Quote Product and Order Product that had changes in the Active layer in production (17 web resources, 6 forms on quotedetail, 1 column on salesorderdetail). It is not a whole-environment layer check. A full check means one layer read per customised component (thousands of calls); proposed to do it only for components planned to be changed.
